YomYom

Flagship SaaS

Restaurant Operations SaaS · Next.js · Supabase · Python · PostgreSQL

A dashboard for restaurant owners with more than one branch. It ingests the daily POS exports, computes KPIs per branch, and flags voids, comps and cash drift that don’t match the receipts, the usual sign of a leak or of fraud. The flags come from plain SQL and Python rules; a language model only explains a flag that already exists. The ≥10% saving is a projection, not a measured result.

Luka

Private Beta

Memory Archive · React Native Expo · PostgreSQL RLS · 546 Tests

An iOS and Android app where families store photos, recordings and stories. Each family is a tenant, and Postgres Row Level Security policies scope every query to the caller’s family, so a bug in the app code can’t leak another family’s data. Media is served through short-lived signed URLs. 546 tests in 50 suites run on every commit, including checks that one tenant can’t read another’s rows.

pico-gpt

From Scratch
Repo →

Transformer Language Model · PyTorch · BPE Tokenizer · KV-Cache · 34 Tests

A small GPT written in PyTorch without nn.MultiheadAttention or a borrowed tokenizer. Multi-head causal attention is written out by hand, the byte-level BPE tokenizer is my own, and generation uses a KV cache so each new token doesn’t recompute the whole prefix. 34 tests check tokenizer round-trips, that hand-written attention matches PyTorch’s SDPA, that cached and uncached decoding give the same logits, and that the model can overfit a single batch.
